# AI Translation Model Comparison
Comparative analysis of AI translation models from English to Turkish

# Project Objective 
This project compares the English to Turkish outputs of two different AI systems, TranslateGemma and DeepL. The translations were evaluated and then post-edited to improve accuracy,fluency, terminology, contextual appropriateness and overall quality.

# Project Information
- Source:BBC
- Artice: What's The Best Way To Learn a New Language?
- Author: Krupa Padhy
- Source Language: English 
- Target Language: Turkish 
- AI Systems Used: TranslateGemma, DeepL 
- Task: AI translation comparison, evaluation,and human post-editing.

# Evaluation Criteria
The AI translations were evaluated according to six quality criteria.
- Meaning
- Fluency
- Terminology
- Context
- Style
- Grammar/QA

An overall score was also assigned to each version

# Results
- TranslateGemma: 4,3/10
- DeepL: 6,7/10
- Human post-editing: 8,3/10

In this project DeepL performed better than Gemma, especially in fluency, contextual accuracy,and grammar QA. The human post-edited version achieved the highest overal score.

# Selected Post-Editing Examples
The project includes examples where both AI systems produced overly literal or contextually inappropriate translations.

Examples Include
- Idiomatic expressions such as "to burst at the seams"
- The word "cheesy" and its contextual meaning.
- Subject and tense relationships in Turkish sentences.
- The phrase "under immersion settings"

These examples demonstrate the significance of contextual adaptation and human post-editing in AI generated translations.

# Key Findings
- DeepL required less post-editing Gemma in this sample.
- Gemma produced more direct and contextually problematic translations.
- Both systems sometimes generated similar literal translations.
- Human post-editing significantly improved naturaless and contextual appropriateness.
- AI translation quality can change depending on terminology,idiomatic expressions and context.
